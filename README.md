# Bath Dream — Client Module

Прототип клиентского сайта Bath Dream.

## Реализовано

- Регистрация по телефону или e-mail.
- Экран подтверждения 4-значным кодом.
- Выбор типа клиента: **Физическое лицо / ИП / Юридическое лицо**.
- Динамические поля профиля под каждый тип клиента.
- Экран успешной регистрации.
- Переход в будущий модуль **«Создать заказ»**.
- Адаптивная верстка в визуальном стиле Bath Dream.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Следующий модуль

После регистрации будет добавлен сценарий:

**Создать заказ → объект → помещения → геометрия → услуги → демонтаж → смета**.
