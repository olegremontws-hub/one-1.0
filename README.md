# Bath Dream — Client Module

Прототип клиентского сайта Bath Dream.

## Реализовано

- Регистрация по телефону или e-mail.
- Подтверждение 4-значным кодом.
- Тип клиента: **ФЛ / ИП / Юридическое лицо**.
- Динамические поля профиля.
- Личный кабинет **«Мои заказы»**.
- Пустое состояние и кнопка **«Создать заказ»**.
- Первый шаг нового заказа: **Новостройка / Вторичный рынок / Дом**, адрес, площадь, этаж, лифт.
- Черновик заказа после сохранения.
- Адаптивная верстка в стиле Bath Dream.
- Workflow для публикации через GitHub Pages.

## Локальный запуск

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```
