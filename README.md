# Bath Dream — Client MVP

Рабочая демонстрационная модель клиентского контура Bath Dream.

## Пользовательский путь

**Регистрация → ФЛ / ИП / Юрлицо → Мои заказы → Создать заказ → Объект → Помещения → Геометрия → Демонтаж → Смета → Карточка заказа**

## Что работает

- Регистрация по телефону или e-mail с демо OTP.
- Тип клиента: ФЛ / ИП / юридическое лицо.
- Проверка ИНН / КПП / ОГРН / ОГРНИП по длине.
- Сохранение клиентского профиля в браузере.
- Список заказов, открытие и повторное редактирование.
- Автосохранение незавершённого нового заказа.
- Объект: тип, адрес, площадь, этаж, наличие лифта.
- Несколько помещений.
- Геометрия:
  - точный режим: длина × ширина × высота;
  - быстрый режим: площадь пола + высота;
  - окна и двери;
  - пол, потолок, периметр, стены брутто, проёмы, чистая площадь стен.
- Каталог демонтажа по физическим элементам.
- Автоподстановка количества из геометрии.
- Редактируемые расчётные ставки.
- Предварительная смета по помещениям.
- Расчёт отходов по выбранным демонтажным позициям.
- Расчёт массы, объёма, мешков и крупногабаритных отходов.
- Логистика: упаковка, вынос, погрузка, транспорт, утилизация.
- Общий итог: работы + логистика.
- Инженерное предупреждение для железобетонных конструкций.
- Smoke-test расчётного ядра.
- Адаптивный интерфейс.

## Важно

Текущие цены, коэффициенты отходов и логистические ставки — **расчётная модель v1 для прототипа**, а не публичная оферта и не подтверждённый коммерческий прайс. Перед коммерческим запуском их нужно актуализировать и утвердить.

Данные MVP сохраняются в `localStorage` браузера. Реальная авторизация, серверная БД, SMS/e-mail OTP, договоры и платежи ещё не подключены.

## Управление заказами

- Статусы: Черновик → Расчёт готов → На согласовании → Договор → В работе → Приёмка → Завершён.
- Дублирование и удаление заказа.
- Экспорт всех данных в JSON и восстановление из резервной копии.
- Печатная расшифровка сметы из карточки заказа.

## Локальный API

Для full-stack режима подготовлен локальный Node API:

```bash
npm run server
```

API запускается на `http://localhost:8787`. Контракт описан в `docs/API.md`.

## Локальный запуск

```bash
npm install
npm run test:smoke
npm run test:api
npm run dev
```

Production:

```bash
npm run build
npm run preview
```
