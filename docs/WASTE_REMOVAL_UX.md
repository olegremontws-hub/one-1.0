# Bath Dream — UX услуги «Вывоз строительного мусора»

Статус: **реализованный MVP v0.11**

## Точка входа

После регистрации клиент попадает на экран **«Услуги Bath Dream»** с двумя карточками:

1. **Демонтаж**
2. **Вывоз строительного мусора**

Вывоз строительного мусора — самостоятельная услуга и отдельный пользовательский сценарий.

## Клиентский путь

### 1. Что нужно вывезти

Клиент выбирает один или несколько типов:

- мешки;
- кирпич и бетон;
- плитка и штукатурка;
- дерево;
- сантехника;
- смешанный строительный мусор.

### 2. Сколько мусора

Доступны способы оценки:

- количество мешков;
- объём в м³;
- «не знаю объём».

Для сценария «не знаю объём» допускается:

- приблизительная визуальная оценка;
- загрузка фото;
- выбор категории объёма: мало / средне / много.

### 3. Условия на объекте

Клиент указывает:

- этаж;
- наличие лифта;
- расстояние от объекта до автомобиля;
- нужен ли вынос;
- кто выполняет вынос: клиент или бригада Bath Dream.

### 4. Когда нужен вывоз

Клиент выбирает:

- дату;
- доступный временной интервал.

### 5. Итог расчёта

На финальном экране показываем:

- выбранный тип мусора;
- объём;
- условия объекта;
- дату и время;
- вынос;
- погрузку;
- транспорт;
- утилизацию;
- итоговую стоимость.

Основное действие: **«Оформить заказ»**.

## Принцип цены

Клиенту показываем человеческие составляющие цены:

**вынос + погрузка + транспорт + утилизация + дополнительные условия**

Не показываем внутренние коэффициенты и служебные нормы.

Пример клиентского объяснения вместо коэффициента:

> 4 этаж без лифта — доплата за ручной спуск.

## Связь с услугой «Демонтаж»

Если клиент приходит из расчёта демонтажа и объём отходов уже рассчитан, Bath Dream подставляет его автоматически.

Пример:

> По вашему демонтажу ожидается ~4,8 м³ отходов. Рассчитать вывоз?

Клиент не должен повторно вводить уже известные системе данные.

## Дизайн

Зафиксированный визуальный подход:

- mobile-first;
- светлый интерфейс;
- крупные карточки выбора;
- бирюзово-зелёный акцент Bath Dream;
- один главный вопрос на экран;
- минимум ручного ввода;
- крупная итоговая стоимость;
- понятное разложение цены;
- прогресс прохождения шагов.

Целевой сценарий:

**Регистрация → Услуги → Вывоз строительного мусора → Что вывозим → Сколько → Условия → Дата → Итог → Оформление заказа**



## Реализовано в v0.11

Рабочий калькулятор доступен из карточки услуги и сохраняет полноценный заказ Bath Dream.

Расчёт включает:

- вынос с объекта;
- погрузку;
- подбор транспортного тарифа по объёму;
- утилизацию;
- доплату за дальний пронос;
- повышенную модель утилизации для тяжёлых отходов.

После сохранения заказ на вывоз подключается к общим модулям:

- история изменений и согласование;
- документы;
- оплаты;
- график выполнения;
- приёмка.

Заказ хранится с `serviceType: waste`.

Тарифы v0.11 являются прототипной расчётной моделью и требуют коммерческого утверждения.
