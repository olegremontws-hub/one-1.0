# AW HOME Marketplace v0.19

## Роль продукта

AW HOME — маркетплейс услуг для полного жизненного цикла недвижимости:

**Недвижимость → Архитектура и Дизайн → Стройка и Ремонт → УправКом → Уход за домом**

После авторизации клиент попадает в каталог, а кабинет остаётся отдельным разделом.

## Каталог

В v0.19 зафиксированы 5 разделов и 30 стартовых услуг. Каждая карточка содержит изображение по смыслу, название, короткое описание, ориентир цены и действие.

Работают:
- поиск по услугам;
- фильтрация по разделам;
- избранное;
- популярные услуги;
- отдельная страница услуги;
- оформление заказа;
- переход в существующие калькуляторы демонтажа, вывоза мусора и чернового ремонта.

## Универсальная страница услуги

Для любой услуги показываются:
- раздел;
- крупное изображение;
- название и описание;
- ориентир стоимости;
- состав услуги;
- последовательность выполнения;
- кнопка оформления заказа.

Для `Демонтажа`, `Вывоза строительного мусора` и `Чернового ремонта` дополнительно доступен переход в уже существующий калькулятор.

## Оформление заказа

Клиент проходит 5 шагов:

1. **Объект**
   - тип объекта;
   - площадь.

2. **Адрес**
   - адресное поле с подсказками;
   - рядом Яндекс.Карта;
   - карта обновляется по введённому адресу.

3. **Параметры**
   - этаж;
   - лифт;
   - подбор исполнителя AW HOME или самостоятельный выбор;
   - обычный / срочный заказ;
   - комментарий.

4. **Дата и время**
   - календарная дата;
   - временной интервал.

5. **Итог**
   - услуга;
   - объект;
   - адрес;
   - дата и время;
   - выбранный способ назначения исполнителя;
   - имя и телефон клиента;
   - ориентир стоимости.

После подтверждения создаётся заявка `REQ-...` и сохраняется в локальном preview-хранилище до подключения серверного API.

## Адресный справочник

Preview работает в двух режимах:

- без внешнего ключа — встроенный демо-справочник адресов Москвы;
- при наличии `VITE_YANDEX_SUGGEST_API_KEY` — адресные подсказки Yandex Geosuggest.

Яндекс.Карта отображается рядом с адресом и получает строку введённого адреса. Для браузерной конфигурации предусмотрены `VITE_YANDEX_MAPS_API_KEY` и `VITE_YANDEX_SUGGEST_API_KEY`.

## Цены

Цены в каталоге пока являются демонстрационными ориентирами и **не являются публичной офертой**. Для услуг с известной базовой единицей интерфейс показывает предварительный расчёт. Финальная цена подтверждается до выполнения.
