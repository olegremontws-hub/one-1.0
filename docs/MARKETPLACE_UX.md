# AW HOME Marketplace v0.18

## Концепция

AW HOME развивается как маркетплейс услуг для полного жизненного цикла недвижимости:

**Недвижимость → Архитектура и Дизайн → Стройка и Ремонт → УправКом → Уход за домом**

Главный экран после регистрации — каталог маркетплейса. Клиент может искать услугу, фильтровать каталог по разделам, добавлять услуги в избранное, переходить в кабинет и открывать свои заказы.

## Разделы

1. **Недвижимость**
   - подбор недвижимости
   - покупка квартиры
   - продажа недвижимости
   - приёмка квартиры
   - оценка недвижимости
   - переезд

2. **Архитектура и Дизайн**
   - дизайн-проект квартиры
   - дизайн ванной комнаты
   - планировочное решение
   - 3D-визуализация
   - подбор материалов
   - комплектация интерьера

3. **Стройка и Ремонт**
   - демонтаж
   - вывоз строительного мусора
   - черновой ремонт
   - электромонтажные работы
   - сантехнические работы
   - ремонт под ключ

4. **УправКом**
   - управление квартирой
   - техническое обслуживание
   - аварийный мастер
   - контроль счётчиков
   - оплата коммунальных услуг
   - контроль подрядчиков

5. **Уход за домом**
   - генеральная уборка
   - уборка после ремонта
   - мытьё окон
   - химчистка мебели
   - уход за паркетом
   - домашний мастер

## Поведение

- Поиск фильтрует услуги по названию, описанию и разделу.
- Навигация по пяти разделам работает как фильтр каталога.
- Избранное хранится локально в браузере.
- Демонтаж, вывоз строительного мусора и черновой ремонт открывают существующие калькуляторы AW HOME.
- Остальные карточки открывают форму заявки с именем, телефоном, адресом и желаемой датой.
- Демо-заявки сохраняются локально до подключения CRM/API.
- Цены в каталоге являются демонстрационными ориентирами и не являются публичной офертой.
