# AW HOME — фирменный интерфейс

Статус: **MVP v0.16**

## Источники бренда

В интерфейс применены пользовательские исходники:

- логотип `awih logo blue 4 темный фон.svg`;
- палитра `ЦВЕТА.svg`;
- семейство `TT Drugs`;
- композиция клиентской главной из макета «Главная заказчик».

## Логотип

В приложение перенесён исходный векторный логотип AW HOME без перерисовки:

`public/aw-home-logo.svg`

Так как исходник рассчитан на тёмный фон, верхняя навигация выполнена в Deep Navy.

## Палитра

Цвета взяты из исходного SVG:

| Название | HEX | Роль |
| --- | --- | --- |
| Deep Navy | `#07172E` | основной фон, текст, навигация |
| Light Gray | `#ECEDF1` | нейтральные фоны и разделители |
| Sand Gold | `#D2A569` | фирменный премиальный акцент |
| Steel Gray | `#828A96` | вторичный текст |
| Silver Lilac | `#BEC0CF` | нейтральные карточки |
| Electric Blue | `#1B5FFD` | CTA, ссылки, активные состояния |
| Signal Red | `#C60D17` | ошибки и критические действия |

## Шрифт

Целевое семейство интерфейса:

**TT Drugs**

CSS настроен на семейство `TT Drugs` через локальные имена шрифта и системный fallback.

Бинарные OTF-файлы не публикуются в публичном репозитории. Для точного отображения в production необходимо разместить лицензированные webfont-файлы в закрытом/разрешённом хранилище или подключить их с разрешённого CDN и затем добавить `@font-face`.

## Главная заказчика

Новая главная повторяет структуру предоставленного макета:

- телефон и город в шапке;
- «Магазин»;
- «Мои заказы»;
- «Создать проект»;
- «Баланс»;
- приветствие клиента;
- вызов сметчика;
- недавние действия;
- текущий заказ;
- создание нового заказа;
- дополнительные услуги;
- вкладки «Проекты / Объекты / Отзывы / Товары»;
- фильтры и сетка проектов;
- контакты в футере.

## Юридические документы

Договор-оферта и КС-2 остаются чёрно-белыми и используют нейтральный печатный шрифт. Фирменная палитра применяется к клиентскому приложению, но не к табличной юридической форме.
