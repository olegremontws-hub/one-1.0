# Bath Dream — фирменный интерфейс

Статус: **MVP v0.15**

## Логотип

Основной логотип хранится в:

`public/bath-dream-logo.svg`

Знак объединяет:

- форму ванной / сервисного контура;
- волну как ассоциацию с Bath Dream;
- монограмму и словесный знак BATH DREAM.

Логотип используется в шапке, футере и как favicon.

## Шрифт

Основной интерфейсный шрифт:

**Manrope**

Начертания: 400 / 500 / 600 / 700 / 800.

Если внешний шрифт недоступен, используется системный sans-serif fallback.

## Принцип интерфейса

Клиентское приложение использует фирменные цвета для:

- навигации;
- CTA-кнопок;
- карточек услуг;
- выбранных состояний;
- прогресса работ;
- иерархической карты выполнения;
- статусов и подсказок.

Юридические документы остаются чёрно-белыми:

- договор-оферта;
- КС-2;
- печатные формы.

Это сохраняет фирменность продукта и одновременно делает документы пригодными для печати и делового использования.

## Адаптивность

На мобильном:

- номер телефона и город скрываются из верхней панели;
- навигация становится компактной;
- логотип уменьшается;
- футер перестраивается в одну колонку.
