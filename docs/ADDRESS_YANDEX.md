# Bath Dream — адрес объекта и Яндекс Карта

Статус: **MVP v0.13**

## Поведение

Во всех трёх услугах используется единый компонент адреса:

- Демонтаж;
- Вывоз строительного мусора;
- Черновой ремонт.

Клиент вводит начало адреса, выбирает точный вариант из адресных подсказок, после чего рядом показывается карта Яндекса с выбранной точкой.

## Интеграция

Для полноценного адресного справочника используются:

- Yandex Maps JavaScript API;
- Yandex Geosuggest API.

Переменные Vite:

```env
VITE_YANDEX_MAPS_API_KEY=
VITE_YANDEX_SUGGEST_API_KEY=
```

При наличии обоих ключей интерфейс подключает Yandex SuggestView и геокодирование, ставит метку на выбранный адрес и центрирует карту.

Без ключей статическая preview продолжает работать: обычное поле адреса остаётся доступным, а справа показывается карта Яндекса через публичный map-widget по введённому адресу. Подсказки из справочника при этом не включаются.

## UX

Desktop:

**Поле адреса / подсказки | Яндекс Карта**

Mobile:

**Поле адреса / подсказки**
**Яндекс Карта**

Карта отображается в чёрно-белом визуальном режиме, чтобы соответствовать интерфейсу Bath Dream v0.12+.
